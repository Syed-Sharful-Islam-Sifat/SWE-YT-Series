# TLS

We know devices communicates each other through internet protocol and industry standard is to use TCP. Although TCP gives us some garauntee on packets arrival from source to destination but it does not secure the data that will travel the internet. but making the data secured over network is the primary responsibility.

So SSL has invented for this so that two devices can exchange data securely.

When the SSL protocol was standardized by the IETF it was renamed to Transport Layer Security(TLS)

The TLS protocol is designed to provide three essential services to all applications running above it: Encryption , Authentication , data integrity

Encryption:
  A mechanism to obfuscate what is sent from host to destination
Authentication:
  A mechanism to verify the validity of identification
